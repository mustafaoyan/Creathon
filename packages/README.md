# packages/

Apps arasında paylaşılacak kod buraya eklenir (örn. ortak TypeScript tipleri,
paylaşılan UI bileşen kütüphanesi, ortak lint/tsconfig presetleri). Şu an tek
bir frontend (`apps/web`) olduğu için henüz paylaşılan bir paket yok; ikinci
bir frontend eklendiğinde `packages/ui`, `packages/config` gibi paketler
buraya eklenebilir.
